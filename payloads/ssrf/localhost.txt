# ============================================================
# Notes for testers
# ============================================================
# 1. Many apps block "127.0.0.1" but miss:
#    - Decimal (2130706433) / Octal / Hex encodings
#    - IPv6 forms, especially IPv4-mapped ([::ffff:127.0.0.1])
#    - DNS names that resolve to loopback (e.g., localtest.me,
#      nip.io, sslip.io, 127.0.0.1.nip.io)
# 2. Pair these with open-redirect payloads for chained SSRF.
# 3. Always confirm the request actually reaches the target
#    (timing, error messages, out-of-band via Burp Collaborator).
# 4. Never run against systems you do not own or lack written
#    authorization to test.
# ============================================================
