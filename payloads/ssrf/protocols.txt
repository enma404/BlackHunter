# Protocol smuggling via redirects
# ------------------------------------------------------------

# ============================================================
# Notes for testers
# ============================================================
# 1. Scheme support is entirely backend-dependent:
#    - PHP + curl        : gopher, dict, file, ftp, ldap, tftp,
#                          and any libcurl-supported scheme
#    - Python requests   : http, https only (by default)
#    - Python urllib     : http, https, ftp, file, data
#    - Java URL          : http, https, ftp, file, jar, mailto,
#                          netdoc
#    - Node.js axios     : http, https only
#    - Node.js fetch     : http, https only
#    - Ruby open-uri     : http, https, ftp, file
#    Enumerate what the target uses before spraying payloads.
#
# 2. gopher:// is the highest-impact scheme. It lets you craft
#    arbitrary TCP payloads to internal services (Redis, MySQL,
#    FastCGI, Memcached, Docker, etc.) and is the standard path
#    from SSRF to RCE. Use it only in scope.
#
# 3. file:// is the fastest way to confirm SSRF + LFI. If it
#    works, /etc/passwd or C:\Windows\win.ini will render.
#
# 4. dict:// is a low-noise way to confirm SSRF and port-scan
#    internal services (returns banner data for many protocols).
#
# 5. UNC paths (file://///host/share) can capture NTLM hashes
#    via Responder — useful for Windows targets.
#
# 6. data:// and php://input can turn SSRF into RCE on PHP
#    targets with allow_url_include=On.
#
# 7. Redirect-based smuggling is often missed by filters that
#    only validate the user-supplied URL, not the final URL
#    after following redirects.
#
# 8. Always confirm with out-of-band (interactsh, Collaborator)
#    before assuming a blind SSRF worked. Some schemes return
#    no response data but still make the connection.
#
# 9. Never use gopher:// to modify, delete, or exfiltrate data
#    from an internal service unless the RoE explicitly allows
#    it. A read-only probe is usually enough to prove impact.
# ============================================================
